# 端到端验证记录（2026-09-06）

本文保留 2026-09-06 的测试条件与结果，不代表当前版本重新执行后的结论。文中的后端 3100 端口、审核范围和行为属于当时版本；当前默认端口为 3101，使用方法见 [运行指南](runbook.md)。原始证据路径属于测试机器，未随仓库分发。

## 环境与口径

- 本机开发环境：Java 25、Spring Boot 后端端口 3100、React/Vite 前端端口 5173。
- Model Router 凭证通过后端环境变量注入，本文不记录 API Key 和带签名图片 URL。
- 完整流水线使用 `MODEL_ROUTER_QA_SCOPE=all`，商品为“轻量通勤托特包”，平台 Amazon，市场 US，无参考图。
- 演示尺寸为用户明确授权的常见设定：宽 38 cm、高 30 cm、厚 12 cm，并在图片中标记为 `DEMO DIMENSIONS - NOT MEASURED`，不代表实物实测。

## 优化前基线

早期完整调用耗时 338.417 秒，生成五张图；初次结果为 1 张通过、3 张未通过、1 张视觉审核异常。复检发现图片模型会生成无来源品牌和错误尺寸，视觉模型也可能漏检看似合理的无来源数字。这一轮仅作为问题发现基线，不作为当前能力指标。

## 优化后完整流水线

## 保存结果复检

将 run-9 的五张 PNG 转为同源 data URL，再通过 `/api/compliance-check` 逐张复检，五次均返回 HTTP 200、`passed=true`。审核同时接收原始商品资料，检查无来源数字、品牌、认证和功效；没有品牌资料时，任何可识别品牌名或 Logo 均要求人工核实或拦截。

## 错误样本回归

保留的旧错误对比图（拼写错误、未授权 YKK 标识）和旧错误尺寸图（将 380 等数值标为 cm）重新检测均返回 `passed=false`，错误样本拦截 2/2。该结果证明规则收紧后仍能识别已知明显问题。

健康检查、单图生成、Amazon/US 合规检测，以及场景、文字、模特三个本地化维度均取得成功响应。本地化图片返回 1024 × 1024。前端桌面和手机视口检查确认尺寸图 data URL 能显示、下载，页面无横向溢出，浏览器无运行时错误。
