# OneLaunch 版本记录

本文件按日期记录主要功能变化。当前行为和接口以 [README](../README.md)、[架构说明](architecture.md) 和 [API 文档](integration-guide.md) 为准；历史验证只代表对应版本和样本。

## 2026-10-08

- 将项目文档整理为项目介绍、产品说明、架构、接口及运行指南。
- 更新三步创作向导、规则浏览、润色、模型目录和 SSE 事件说明。
- 明确尺寸图本地排版、自动修复条件和图片检查与详情页的完成边界。
- 将方案材料改写为项目详解，清理重复说明和过期的运行信息。

## 2026-10-04

- 更新前端页面结构，提供三步创作向导、生成工作台、市场规范和独立工具入口。
- 引入白底墨字的界面样式、Lucide 图标和首页起飞动画。
- 增加卖点与关键词润色、规则快照接口。
- 平台和市场规则改为带编号的硬性与风格条目，生成和检测共用硬性规则。
- 市场检查限定为图片可见的客观要求，平台默认市场映射由后端提供。
- 强化模特图的着装要求，并同步生成、检测和修复条款。

## 2026-10-03

- 将图类生成与质检要求整理到 `ImageQualityContract`。
- 增加首张参考图的视觉描述，在生成、检测和修复中复用商品事实。
- 增加本地清晰度、噪点、场景与人物存在性预检。
- 增加修复严重度阈值和可配置轮数；噪点类问题优先使用干净白底基准重绘。
- 增加服务端预配置的编辑诊断网关及请求级路由选择。
- 编辑网关支持 `chat` 和 `openai-images` 两种请求格式。

## 2026-09-09

- 更新当时的端口、P3 检查、图片修复和本地图片处理说明。
- 同步历史架构、业务流程及产品原型材料。

## 2026-09-08

- 后端默认端口调整为 3101。
- 使用 P3 原始商品参考图检查商品本体一致性，修复时保留原始商品基准。
- 单图工具和槽位修改后的图片增加自动复检。
- 白底图与对比图增加原图像素处理路径，失败时回退模型。
- 详情页模型提示词改为英文输出，保留模板降级。

## 2026-09-07

- 工具工作台切换时保留运行中的组件。
- 修正编辑提示词中修改指令与保持性约束的冲突。
- 统一流水线与独立检查的通用判定规则，并加入白底检测容差。
- 增加按结构化建议修复和再次检查的工作流程。
- 图片处理完成后结果留在生成工作台查看。

## 2026-09-06

- 增加全图类检查、规则知识库及结构化审核结果。
- 区分检查通过、未通过与人工复检状态。
- 增加尺寸图本地渲染和视觉 JSON 格式恢复。
- 本地化支持背景场景、文字语言和模特形象。
- 保存单商品、单平台真实网关 [验证记录](e2e-evidence-2026-09-06.md)。

## 2026-08-30

- 增加参考图生成、模型选择、SSE 过程展示和单图重生成。
- 每个目标平台分别处理完整五图。
- 增加视觉模型审核和修复指令。
- 详情页生成成为独立能力。
- 增加图片预览、下载和单图工作台。

## 2026-08-27 至 2026-08-29

- 后端完成 Java 25、Spring Boot 4.0.6、Spring AI 2.0.1 的工程迁移。
- 主网关图片能力适配 `/chat/completions`，图片本地化使用同步编辑。
- 整理前后端启动与构建命令，移除旧后端实现和未使用入口。

更细的提交信息可通过 `git log` 查看。
